# Tools not opened in a browser

3236 of 3700 tools were **not** opened in Chromium. They passed only the static checks (link check, script syntax check, canonical/title check). The full list with a `browser_tested` flag is in `tool-inventory.csv`.

Sampled for browser testing: 14 random tools from each of the 24 categories, every repaired tool, and 14 must-work tools.
