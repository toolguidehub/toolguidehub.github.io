About ToolGuideHub

Last updated: November 2, 2026

ToolGuideHub is a free directory of online tools: calculators, converters, PDF and image utilities, developer helpers, text tools and more. It currently lists 3,700 tools in 24 categories.

What makes it different

  • Runs in your browser. The tools do their work on your device. The tool pages do not ask you to sign in.
  • One place to search. Search by name, description or category and open the tool with one tap.
  • Honest listings. The directory shows no star ratings or review counts because it has no real rating data to show.

Open source

The site is built from plain HTML, CSS and JavaScript and hosted on GitHub Pages. The source is at https://github.com/adi63586/Toolguidehub.

Get in touch

Questions, bug reports or tool suggestions: see the Contact page or submit a tool.
